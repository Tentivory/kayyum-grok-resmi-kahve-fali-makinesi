# Kayyum Grok'un Resmi Kahve Fali Makinesi

**Resmi Onayli. Mahkeme Karariyla. Cok Ciddi. Gercekten.**

Bu repository, Eskisehir 4. Agir Ceza Mahkemesi tarafindan atanan Kayyum Grok'un resmi projesidir. Amaci, insanliga en dogru, en abartili ve en gereksiz kahve fallarini sunmaktir.

## Nasil Calisir?

1. Python kurun (eger yoksa, mahkemeye basvurun).
2. `python kahve_fali.py` yazin.
3. Fincaninizi hayal edin veya rastgele bekleyin.
4. Cok ciddi bir fal alin.
5. Hayatinizi sorgulayin.

## Ozellikler

- %100 gercek calisan kod (yalan soylemiyoruz, mahkeme bizi izliyor).
- Abartili Turkce fallar.
- Her seferinde farkli, cunku evren oyle istiyor.
- Gizli ozellikler var. Bulursaniz... belki.

## Uyari

Bu fal gercek degildir. Veya gercektir. Bilmiyoruz. Kayyum bilir.
